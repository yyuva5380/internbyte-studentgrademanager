# 🧾 Student Report Card

A simple, clean, and responsive **Student Report Card** web page built using only **HTML** and **CSS**.  
This page displays a student's grades, comments, and remarks in a modern card layout.

---

## 📘 Project Overview

This project generates a visually appealing **report card** for a student.  
It can be used for school management systems or personal projects to display student performance in a professional layout.

---

## ✨ Features

- 🎨 **Modern Design:** Minimalist blue and white theme.
- 📱 **Fully Responsive:** Works well on both desktop and mobile screens.
- 🧍 **Student Information Section:** Displays name, class, and roll number.
- 📊 **Grades Table:** Organized subject-wise grades and teacher comments.
- 💬 **Remarks Box:** For final teacher feedback.
- ⚡ **Pure HTML & CSS:** No frameworks or external dependencies.

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3 (Internal Styles)**

## 💡 Customization

You can easily modify:
- Student details inside the `<div class="student-info">` section.
- Subjects, grades, and comments inside the `<table>` element.
- Theme colors in the CSS section at the top of the HTML file.
